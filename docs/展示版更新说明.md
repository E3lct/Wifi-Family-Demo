# 展示版更新说明

## 2026-10-24 独立展示整理

本次从原家庭安全检测系统 Web 原型整理出独立展示仓库，原开发仓库保留私有。原项目周期为 2025.09—2025.11，原项目已取得软件著作权登记；下列改进属于 2026 年，不回写为 2025 年成果。

- README 说明模拟数据、前端功能、聊天入口及未提供完整设备后端的边界。
- 聊天默认固定演示回复；真实模型仅通过可选同源代理接入，服务端需自行实现。
- SSE 解析增加跨分片缓冲、UTF-8/CRLF/末行处理、结束标记与空回复检查。
- Markdown 经 DOMPurify 清理，用户输入作为文本显示；增加超时和重复发送保护。
- 提供可访问的快捷问题按钮、输入标签、滚动容器和中文输入法发送保护。
- 增加模拟模式提示，修正侧栏遮挡与深色标题对比度，移除无测评依据的识别精度数字。
- 设备后端地址未配置时不自动连接，保存/重连按钮禁用。
- 增加无密钥配置示例、解析器测试和本地界面截图。
- 在独立展示目录更新依赖锁文件及 Vue ESLint 插件；发布前 npm audit 为 0 项告警。

验证：生产构建、4 项解析器测试、聊天相关文件定向 ESLint、浏览器页面切换与桌面/移动布局检查。代理模式通过拦截响应测试，不表示真实模型或设备后端已上线。全量 ESLint 尚有既有问题，构建仍有大包提示。
